# Восстановление SkillSprint в Figma

Локальный плагин для исходного файла: https://www.figma.com/design/yaXHM7qEsWFob4Zgcb1EwD

1. Открой файл в **Figma Desktop** с правом редактирования.
2. В меню **Plugins → Development → Import plugin from manifest…** выбери `manifest.json` из этой папки.
3. Запусти **Plugins → Development → SkillSprint — Repair screens**.
4. Нажми **Восстановить экраны** и проверь результат на холсте.

Плагин заполняет пять пустых заготовок, добавляет форму цели, связывает навигацию и переносит главные компоненты на отдельную страницу. Первоначальные импорты 2:2 и 4:2 перемещаются в архив, а не удаляются. Все подписи — обычные TEXT-слои; кнопки и остальные повторяющиеся элементы — экземпляры компонентов. Используется Inter и официальные Heroicons.

Нет сетевых запросов и внешних зависимостей. Плагин предназначен только для указанного исходного файла и остановится, если пустые заготовки уже изменены. Код подготовлен и проверен синтаксически; выполнение и внешний вид в Figma требуют проверки в редакторе. Не считается применённым исправлением до фактического запуска.

## Завершение после заполнения экранов

`finish-in-editor.js` предназначен для уже заполненных шести экранов. Его можно вставить в RunJSOnce и запустить кнопкой **Run**. Он исправляет подписи круга прогресса, контраст кнопок, прозрачность контейнеров Heroicons и высоту карточек; располагает экраны в сетке 3 × 2; переносит компоненты и старые импорты на отдельную страницу. Повторное выполнение не создаёт новые экраны.

Дождись окна с отчётом и сохрани его содержимое перед закрытием плагина. Результат необходимо проверить на холсте.

## Применено 30 сентября 2026

Исправление выполнено в исходном файле. Отчёт редактора сохранён в `applied-report.json`: шесть экранов содержат 25–61 текстовый слой каждый, отсутствующих шрифтов и растровых изображений нет. Создана страница компонентов и архив старых импортов; настроено 34 перехода. Шесть отклонённых переходов ведут на уже открытый экран и не нужны для навигации.

В режиме прототипа визуально проверены обзор, план, тренажёр, AI-интервью, прогресс и форма цели. Проверены переходы по боковому меню и открытие формы изменения цели из плана. Снимки проверки сохранены в каталоге визуализаций текущего чата.

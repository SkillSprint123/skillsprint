# SkillSprint

Перед архитектурными изменениями прочитай `docs/architecture.md`.
Это источник решений о контракте BroJS, нанофронтендах и отложенной миграции.
Текущий стек — `docs/stack.md`, размещение файлов — `docs/structure.md`.

- Сохраняй публичные `default` / `mount` / `unmount` в `src/index.tsx`.
- Сохраняй форму контракта v1 и экспорты `packages/contracts/src/index.ts`.
- Корень собирается BroJS/Webpack; переход на Vite требует отдельного поручения.
- Все стили приложения — CSS-in-JS через Goober, рядом с компонентом в `styles.ts`.
  Не добавляй `.css`, `.scss`, CSS Modules, Chakra UI, Emotion или глобальный reset.
- Стили модуля должны принадлежать его контейнеру и удаляться при `unmount`.
- Данные и контракты описывай Zod-схемами в `schemas.ts`.
  Типы выноси в `types.ts` и выводи через `z.infer`, без дублирования схем.
  Для API React, DOM и библиотек используй их штатные типы в `types.ts`.
- Состояние каждого нанофронтенда изолировано; общего Redux-store между нанос нет.
- Ключ GigaChat хранится только на сервере; не отключай проверку TLS.
- Не создавай резервные копии и Git-репозиторий без отдельного поручения владельца.
- После изменений проверяй `npm run check` и `npm run build:prod`.
